# Vacancy detail template — section index

Route template: /careers/vacancies/:slug  
Source: alexandra-montessori/src/pages/VacancyDetail.jsx

1. 01-dynamic-page-header — header/SEO for either a bound open Job or the not-found title.
2. 02-role-detail-and-application — the live-job public detail section with metadata, summary, rich description, benefits, internal/external application branch and return link.
3. 03-not-found-or-closed-fallback — the mutually exclusive public fallback section rendered when no open Job matches.

The template shell is visually editable; the selected Job record remains authoritative.
