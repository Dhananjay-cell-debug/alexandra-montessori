## Parity authority

The WordPress canvas must load the real route and the same React components. No generic contact mock-up is acceptable. Every `PLAN.md` below starts from an existing visible/functional section in `Contact.jsx`, `ContactLocation.jsx`, or `ContactForm.jsx`.

Branch facts stay bound to the corresponding Nursery record. A branch page may have visual overrides, but it must not create a second hidden address, phone, email, hours, postcode, or image source.
